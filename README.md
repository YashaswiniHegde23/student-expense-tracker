# Student Expense Tracker

A full-stack web application for managing personal expenses, monthly budgets, and user account details.

## Project Overview

Student Expense Tracker helps students keep track of their expenses and manage their monthly budget through a simple and user-friendly interface.

The application includes:

- User registration and login
- JWT-based authentication
- Expense management
- Expense filtering and sorting
- Monthly budget management
- Dashboard with expense summaries
- Recent expenses
- Profile management
- Responsive dark-themed interface
