# 💰 Student Expense Tracker

A Spring Boot REST API that helps students manage their daily expenses efficiently. The application provides secure user authentication, expense management, budget tracking, analytics, filtering, and Excel report generation.

---

## 🚀 Features

- User Registration & Login
- Secure Password Encryption (BCrypt)
- Expense Management (CRUD)
- Search Expenses by Title
- Filter Expenses by Category
- Filter by Date & Date Range
- Filter by Amount
- Dashboard Statistics
- Monthly Expense Summary
- Category-wise Expense Summary
- Monthly Budget Management
- Remaining Budget Calculation
- Budget Exceeded Alert
- Pagination
- Sorting
- Export Expenses to Excel

## ⚙️ Setup

1. Clone the repository

```bash
git clone https://github.com/YashaswiniHegde23/student-expense-tracker.git
```

2. Open in IntelliJ IDEA

3. Configure MySQL

4. Update `application.properties`

5. Run the Spring Boot application
